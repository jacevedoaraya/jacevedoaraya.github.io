# jacevedoaraya.github.io

Página principal (portafolio) de Juan Pablo Acevedo Araya, publicada con GitHub Pages.
Main portfolio page, published with GitHub Pages.

El contenido se basa en el repositorio [Cybersecurity-docs](https://github.com/jacevedoaraya/Cybersecurity-docs).
Todo está en un solo archivo: `index.html` (HTML + CSS + JS, sin dependencias ni build).

## Labs automáticos
Al abrir la página, se lee la tabla "📂 Contenido" del README de Cybersecurity-docs.
Cualquier carpeta de esa tabla que no esté en `index.html` aparece sola en la sección **Nuevos**.
Para pasarla a una categoría (Blue Team, Pentest, etc.) copia un bloque `<article class="lab">` en `index.html`.
